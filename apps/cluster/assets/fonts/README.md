# Custom Fonts

Place your licensed Futura files in this folder to be loaded by the Qt app at startup.

Supported filenames searched by default:

- Futura.ttf
- Futura.otf
- Futura-Medium.ttf
- Futura-Book.ttf
- FuturaPTBook.otf
- FuturaPTMedium.otf
- FuturaStd-Book.otf

If no custom font is found, the app falls back to a system UI font.

## Notes

- Ensure your product license permits bundling/distribution.
- Keep only licensed files in this folder.
